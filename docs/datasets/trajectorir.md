# trajectoRIR

`trajectorir` · measured · 2025 · wave 2 · status **planned**

8648 stationary RIRs sampling an L-shaped trajectory (RT 0.5 s room) with a dummy head, 3 first-order Ambisonics mics, circular (16/4 ch) and linear (12 ch) arrays; plus moving-microphone recordings.

# MIRACLE

`miracle` · measured · 2023 · wave 3 · status **planned**

856,128 single-channel IRs across 4 scenarios with a planar 64-channel microphone array; 64 x 64 source grids at two distances, a dense 33 x 33 grid, and a reflective-panel case.

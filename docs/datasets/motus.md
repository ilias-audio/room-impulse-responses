# Motus

`motus` · measured · 2021 · wave 2 · status **planned**

3,320 higher-order Ambisonic RIRs measured with an Eigenmike em32, 4 loudspeaker positions and 830 furniture configurations in a single room at Aalto Acoustics Lab; 3D models for each configuration (spherical photos not fetched).

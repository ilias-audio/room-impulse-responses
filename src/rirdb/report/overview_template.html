Picking IRs

Every analysed IR is a row of the DuckDB view corpus (one row per IR, 334+ columns). corpus_dedup adds dup_of for sample-identical copies, and clean_rooms is the subset most work should start from. The subsets used throughout this report are nested:

measured is false for production libraries (Voxengo, hardware-reverb and plate captures). ir_kind separates rooms from anechoic captures (MIRACLE, RWCP, Surrey), outdoor spaces, vehicles, devices, scale models and virtual reconstructions. preferred keeps one representation per measured position (OpenAIR's B-format over its mono copy, MRTD's omni over its KEMAR). The clean subset also drops files the audit marks as sweeps or chirps, tonal, not decaying, or with dropouts; it does not filter on grade or noise, so add those conditions yourself.

From the command line (inside a job)

sbatch -p computeshort jobs/quick_cpu.sh pixi run rirdb query \
  "grade IN ('A','B') AND t30_mid BETWEEN 0.8 AND 1.2 AND NOT flag_nonstationary_noise" \
  --view clean_rooms --columns ir_id,dataset_id,room_label,t30_mid,edt_mid,c80_mid,drr_bb --limit 0 --csv picks.csv

From Python

from rirdb.query import connect
con = connect()                       # views: corpus, corpus_dedup, clean_rooms, irs, rooms, metrics, audit
df = con.execute("""
    SELECT ir_id, dataset_id, room_label, locator, t30_500, t30_1000, c80_mid, drr_bb
    FROM clean_rooms
    WHERE valid_t30_500 AND valid_t30_1000 AND training_use = 'allowed'
""").df()
# audio: rirdb.adapters.get_adapter(...).load(json.loads(locator), rirdb.paths.files_dir(dataset_id))

import pandas as pd

Signal integrity

Four questions, each answered by a check that runs on every analysed file. The audit (rirdb audit) works on the same channel the analysis used, after the same onset crop.

Pre-delay in the source files
Time from file start to the ISO onset (log scale); removed before analysis
Peak-to-noise ratio
Peak level over the broadband noise floor, dB
Noise-floor bursts
Loudest 20 ms frame over the median frame after the decay, dB (stationary noise ≈ 1–3 dB)
Noise-floor drift
Last third minus first third of the floor, dB (fade-outs and gating show as large negative values)

Flag rates per dataset

Share of each dataset's analysed IRs carrying the flag. Columns are the audit flags, then the analyzer's own quality flags. Empty cells are zero.

CLAP map

Drag to pan, scroll or pinch to zoom, click a point to list its nearest neighbours. Distances are cosine distances in the 512-d CLAP space, so they do not depend on the 2-D layout; UMAP keeps local neighbourhoods but not global distances. CLAP also hears the recording chain (microphones, sample rate, processing): an IR's nearest neighbour comes from its own dataset almost every time, which is why the datasets form islands. Use Other datasets to find the acoustically closest IRs from elsewhere.

What is measured

Per IR and per octave band (63 Hz–8 kHz, IEC 61260-1 class-1 filters) plus a band-limited broadband signal, after trimming digital silence, estimating noise explicitly and cropping at the ISO onset. Multichannel files are analysed on one channel (omni or W, a reference capsule, or both ears).
